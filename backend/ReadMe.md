# ⚙️ Flask Forecasting API

A Flask-based API for time series forecasting 

---

##Quick Setup

### Clone the Repository
git clone git@github.com:weldensieteklay/React-Python-Research-Project.git 
cd backend

### Create a Virtual Environment
python -m venv venv

### Install Dependencies
pip install -r requirements.txt

### Run using fast api 
 uvicorn main:app --reload

 ### Running server
local: http://127.0.0.1:5000/
